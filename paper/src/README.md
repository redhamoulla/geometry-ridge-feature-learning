# Conditional Geometric Register of Observations — Version 7 (English)

This archive contains the English LaTeX source of:

**Conditional Geometric Register of Observations — From Ridge to Feature Learning: Invariants, Diagnostics, and Dynamics**

Author: Redha Moulla  
Affiliation: AXIA, France

The author's personal website is intentionally not included in the manuscript.

## Compilation

```bash
make pdf
```

The `Makefile` uses `bibtex.original` when available and otherwise falls back to `bibtex`.

## Contents

- `main.tex`: English manuscript;
- `references.bib`: bibliography;
- `assets/`: English-language figures used by the manuscript;
- `Makefile`: compilation commands.

A standard TeX Live installation with `pdflatex`, BibTeX, and the packages declared in `main.tex` is required.
