# Conditional Geometric Register of Observations

[![CI](https://github.com/redhamoulla/geometry-ridge-feature-learning/actions/workflows/ci.yml/badge.svg)](https://github.com/redhamoulla/geometry-ridge-feature-learning/actions/workflows/ci.yml)

Research paper and reproducible simulation code for:

> **Conditional Geometric Register of Observations — From Ridge to Feature Learning: Invariants, Diagnostics, and Dynamics**

The repository studies a conditional, non-scalar description of each training observation,

\[
\mathfrak D_{i\mid S}=(G_S,\Gamma_i,\alpha_i),
\]

where `G_S` is the geometry induced by the context set, `Γ_i` is the positive observation operator contributed by a point, and `α_i` is its cotangent effort. The paper shows how leverage, information gain, Cook-type displacement, influence functions, and several Shapley-style values arise as scalar projections or contextual averages of this richer register.

```text

├── paper/                  English manuscript sources
```

## Installation

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

A Conda/Mamba environment is also provided:

```bash
mamba env create -f environment.yml
mamba activate geometric-register-v7
```

## Reproduce the simulations

Compact exact checks:

```bash
python run_experiments.py --suite quick
```

Public experiments:

```bash
python run_experiments.py --suite public
```

Private SeLoger experiments:

```bash
python run_experiments.py --suite seloger --seloger-csv '/path/to/selogerdata(1).csv'
```

The private SeLoger table is not committed. Its expected schema is documented in [`data/README.md`](data/README.md).

## Paper

The complete English LaTeX manuscript is stored under [`paper/`](paper/). The figures used in the manuscript are generated by the experiment scripts and documented in the paper README.

## Reproducibility scope

The algebraic, nonlinear, California Housing, and Concrete experiments use synthetic or public data. The SeLoger experiments require the private source table and therefore cannot be reproduced from this repository alone. See [`docs/REPRODUCIBILITY.md`](docs/REPRODUCIBILITY.md).
